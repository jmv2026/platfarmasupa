# Documentação da Aplicação PlatFarmaSupa

Este diretório contém a documentação completa da aplicação **PlatFarmaSupa**, abrangendo as páginas da UI, módulos de código, botões de interação, assim como o esquema de base de dados Supabase (tabelas, views, funções e triggers).

## Estrutura de Documentação

- **docs/OVERVIEW.md** – Visão geral da aplicação e índice com links para todas as secções.
- **docs/pages/** – Descrição de cada página (rotas, componentes principais, permissões).
- **docs/modules/** – Resumo dos módulos reutilizáveis e utilities.
- **docs/buttons/** – Lista de todos os botões de interface, o que fazem e quem tem permissão para os usar.
- **docs/database/** – Catálogo das tabelas, views, funções e triggers do Supabase, incluindo assinaturas SQL e explicações de lógica.

A documentação está escrita em **Português (Portugal)** para corresponder ao idioma do código‑fonte.

> **Nota**: Algumas páginas e módulos ainda não foram documentados. O plano futuro inclui gerar documentação para cada ficheiro sob `src/app/**`.
