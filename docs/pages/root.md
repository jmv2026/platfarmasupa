# Página Root (Home)

**Rota:** `/`

Esta é a página inicial da aplicação, normalmente redireciona para o dashboard ou apresenta um resumo rápido.

- **Componente principal:** `src/app/page.tsx`
- **Permissões:** Todos os utilizadores autenticados.
- **Funcionalidade chave:** Exibe atalhos para as áreas principais (Dashboard, Pedidos, Stocks, etc.).
