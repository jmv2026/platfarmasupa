Fluxo de Sincronização Incremental (Método A)

MS Access ➜ Supabase Método A: Tabela Local de Controlo PlatFarmaSupa

Vantagem Estratégica: O Método A não requer qualquer alteração às tabelas ou estruturas do ERP Primavera. Toda a gestão incremental é governada pela tabela local tbl_Sync_Controlo, criada de forma 100% autónoma pelo VBA.

1. Pilares do Mecanismo

1. Pre-Flight Check a Custo Zero

Antes de ligar o cursor e antes de qualquer requisição de rede, valida se há dados mais recentes que o último carimbo. Se não houver, aborta de imediato.

2. Filtragem Delta na Origem

Lê estritamente registos com [data] > UltimoValor, minimizando drasticamente o consumo de memória no Access e a largura de banda.

3. Lotes HTTP Transacionais

Envia lotes de 500 registos JSON para as funções RPC no PostgreSQL com cláusula ON CONFLICT DO UPDATE (idempotente).

4. Especificação da Tabela tbl_Sync_Controlo

Campo Tipo Access Função Exemplo
TipoSync VARCHAR(50) [PK] Chave primária do módulo "FATURAS", "MOVIMENTOS", "STOCK"
UltimoValor VARCHAR(100) Último timestamp ou ID registado "2026-11-20 18:45:00"
UltimoTotalRegistos LONG Quantidade da última carga 124
DataHoraExecucao DATETIME Momento exato da confirmação 21/11/2026 15:10:00
Status VARCHAR(50) Resultado operacional "SUCESSO"

5. Como Forçar Re-sincronização Total (Reset)

Se necessitar de re-exportar todo o histórico, basta executar na Janela Imediata do VBA (CTRL + G):

Call ResetControloFaturas       ' Para faturas
Call ResetControloMovimentos    ' Para movimentos
Call ResetControloStock         ' Para stock
