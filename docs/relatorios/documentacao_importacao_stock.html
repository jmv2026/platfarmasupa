Documentação Técnica e Operacional — Processos de Importação de Stock

Projeto: PlatFarmaSupa (Sermail)  |  Tabela Alvo: public.stock e public.movimentos

Esta documentação descreve a arquitetura de armazenamento de saldos de stock na plataforma PlatFarmaSupa e os procedimentos disponíveis para atualizar a tabela public.stock via ficheiro web ou sincronização direta do MS Access.

1. Arquitetura Geral do Stock na Plataforma

Stock Disponível = Soma(Entradas ES / Stock Base) - Soma(Saídas SS / Pedidos)

2. Estrutura da Tabela public.stock

Coluna Tipo Obrigatório Descrição / Regra de Preenchimento
iduuidSim (Auto)Gerado automaticamente (gen_random_uuid()) ou lido do ficheiro.
cliente_sertextSimSigla do cliente na Sermail (ex.: AOP, MAX, CRD).

3. Comparativo dos Dois Processos de Importação

Característica Processo 1: Ficheiro Web (Configuração > Stocks) Processo 2: MS Access Direto (VBA -> RPC)
Origem dos Dados Ficheiro .xlsx, .xls, .csv ou .txt analisado por parseStockFile. Query direta no MS Access (DAO.Recordset) enviada via access_sync_stock.bas.
Intervenção Manual Exportar ficheiro + Upload na página de Configuração com grelha de pré-visualização. 1 Clique num botão dentro do MS Access (Call AtualizarStockSupabase).
Gravação Transacional Limpa a tabela via limparStockAction e envia lotes de 500 linhas para importarStockAction. Execução atómica no PostgreSQL via RPC public.sync_stock_from_access.
